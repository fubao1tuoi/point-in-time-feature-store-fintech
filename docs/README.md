# Project documentation

Thư mục này sẽ chứa tài liệu vận hành và thiết kế được cập nhật trong quá trình triển khai:

- `architecture.md`: kiến trúc và luồng dữ liệu.
- `data_contract.md`: schema, constraints và data-quality rules.
- `data_dictionary.md`: ý nghĩa được công bố của các file, cột và nhóm feature IEEE-CIS.
- `entity_key_decision.md`: phân tích và quyết định surrogate entity key.
- `feature_catalog.md`: danh mục và semantics của feature.
- `runbook.md`: cách chạy pipeline và xử lý lỗi.
