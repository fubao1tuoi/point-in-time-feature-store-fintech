# Project documentation

Thư mục này sẽ chứa tài liệu vận hành và thiết kế được cập nhật trong quá trình triển khai:

- `architecture.md`: kiến trúc và luồng dữ liệu.
- `data_contract.md`: schema, constraints và data-quality rules.
- `data_dictionary.md`: ý nghĩa được công bố của các file, cột và nhóm feature IEEE-CIS.
- `entity_key_decision.md`: phân tích và quyết định surrogate entity key.
- `pit_time_policy.md`: cutoff, current-event và same-timestamp semantics.
- `DE_CUONG_DE_TAI_PIT_FEATURE_STORE.md`: bản nguồn đề cương chi tiết, dễ chỉnh sửa.
- `POINT_IN_TIME_CORRECT_FEATURE_STORE.pdf`: bản PDF đề cương để gửi hoặc nộp.
- `feature_catalog.md`: danh mục và semantics của feature.
- `BAO_CAO_TONG_QUAN_POINT_IN_TIME_FEATURE_STORE.md`: báo cáo tổng quan tiếng Việt về đề tài,
  kiến trúc, công việc đã hoàn thành, kết quả và hạn chế.
- `BAO_CAO_POINT_IN_TIME_FEATURE_STORE_UPDATED.pdf`: bản PDF A4 mới nhất, gồm 9 mục tiêu, kế hoạch
  Google Cloud và phần giải thích lựa chọn/cấu hình CatBoost;
  dùng ngôn ngữ dễ hiểu để đọc, chia sẻ hoặc trình bày.
- `runbook.md`: cách chạy pipeline và xử lý lỗi.
